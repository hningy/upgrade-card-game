# 工程结构

## 总体结构

项目采用 Vite + React + TypeScript。规则引擎不依赖 React，界面通过 `GameSession` 获取快照并调用动作。

```text
upgrade-card-game/
  index.html
  package.json
  vite.config.ts
  public/
    card-art/                   浏览器实际加载的牌面图片
    audio/                      裁掉最后一秒后的背景音乐
  src/
    main.tsx                    React 入口
    app/
      App.tsx                   页面状态、布局和交互流程
    components/
      cards/
        PlayingCard.tsx         牌面图片、点数和特殊牌面
      game/
        TableParts.tsx          座位、叫主牌和吃分区
      dialogs/
        GameDialogs.tsx         规则、抛硬币、亮牌和结算弹窗
    audio/
      useGameAudio.ts           阶段音乐、音量、静音与自动播放处理
    game/
      types.ts                  牌局、动作、阶段等类型
      cards.ts                  牌组、排序、牌力与基础常量
      rules.ts                  叫主、跟牌、甩牌和赢墩规则
      settlement.ts             积分与升级结算
      engine.ts                 完整牌局状态机和 AI 调度
      ai.ts                     简单/一般/高级 AI 与蒙特卡洛

      global.css                全局布局、牌桌、牌面和响应式样式
  tests/
    game/
      engine.test.ts            规则边界与完整对局回归
  docs/
    升级规则.md                 当前生效规则
    规则原始版.md               用户最初提供的规则
    规则模拟报告.md             规则可行性验证结果
    牌面生成提示词.md           AI 牌面素材生成规范

  tools/
    upgrade_simulation.py       Python 独立规则模拟器
```

## 分层职责

### `src/game`

规则引擎是唯一可以判断动作是否合法的地方。

- `cards.ts`：54 张牌、自然点数和牌力排序。
- `rules.ts`：叫主候选、跟牌校验、甩牌校验、当前赢家。
- `settlement.ts`：0、40、45、65 分对应的升级结果和原因。
- `engine.ts`：发牌、叫主、起义、打底、出牌、亮牌和下一局。
- `ai.ts`：三个难度级别和隐藏信息蒙特卡洛模拟。

界面不能直接修改手牌或分数，所有状态变化都应经过 `GameSession`。

### `src/app`

`App.tsx` 负责：

- 订阅 `GameSession` 状态。
- 驱动发牌、AI 行动、倒计时和阶段切换。
- 处理玩家叫主、打底、出牌、建议和托管开关。
- 渲染牌桌、吃分区、结算和设置弹层。

### `src/components`

通用组件放这里。目前牌面绘制和图片加载集中在 `PlayingCard.tsx`。

### `public/card-art`

只放游戏运行时可以直接访问的最终素材。`assets/card-art/source` 保存未经压缩和裁切的原始文件。

## 牌局状态流

```text
coin
  → dealing
  → revolt / redeal
  → chooseBottom
  → coin（主家选择相同时）
  → burying
  → reveal
  → playing
  → trickReview
  → finalReveal
  → roundEnd
```

托管、自动出牌和 15 秒超时都调用同一个规则引擎，不绕过合法动作检查。

## AI 分层

- 简单：随机和最低合法性优先。
- 一般：队友、牌权、分牌和主牌控制的基础权重。
- 高级：生成符合公开信息的隐藏手牌，对关键候选动作执行 32 次小规模模拟。

AI 的观察来源：

- 自己的手牌
- 已公开出牌
- 已公开底牌和弃牌
- 自己作为叫主者时知道的令花色
- 公开的叫主者、当前最大和得分

AI 不直接读取其他玩家的真实手牌或暗令。

## 背景音乐

- 发牌、叫主、起义和打底：`lobby.wav`
- 正式出牌和本墩展示：`gameplay.wav`
- 末墩亮牌和本局结算：`settlement.wav`
- 单张发牌：`deal.wav`
- 玩家或 AI 出牌：`play-card.wav`

浏览器首次打开时可能禁止自动播放。用户第一次点击或按键后会自动尝试启动，也可以使用顶部的“启动音乐”按钮。音量和静音状态保存在本地。

源文件保留在 `assets/audio/source`。重新生成网页版本：

```powershell
python tools/prepare_audio.py
```

脚本会把三个文件统一裁掉最后 1 秒，并生成约 22.05kHz、单声道、16-bit 的 WAV。

发牌与出牌音效由脚本生成：

```powershell
python tools/generate_card_sfx.py
```

## 本地开发

```powershell
npm install
npm run dev
```

测试和构建：

```powershell
npm test
npm run build
```

独立规则模拟：

```powershell
python tools/upgrade_simulation.py --hands 5000 --seed 20261022
```
